## ⭐ 한 줄 가치 제안

> **"베테랑이 며칠 걸려도 다 풀지 못하던 스케줄링 퍼즐을, 시스템이 5초 안에 초안을 만들고 베테랑은 검토·수정만 하는 구조."**

---

## 1. 핵심 메시지 (3가지)

### 메시지 1 — **납기를 지키면서 손실은 줄인다**
- 납기 준수율 **93% → 99%** (OEM 신뢰도 확보)
- 다이/노즐+금형 변경 횟수 **-30%** (직접 원가 절감)
- 변동 영향 파악 **4시간 → 5분 (-98%)**

### 메시지 2 — **베테랑 의존을 시스템 의존으로**
- 한 사람의 25년 노하우 → 시스템에 명문화 → 후임도 동일 결정 가능
- 휴가·인사이동 시 운영 차질 해소
- 신입 양성 시간 단축

### 메시지 3 — **사람의 시간을 고부가 업무로 전환**
- 생산관리자 스케줄링 작업 **주 24시간 → 12시간** (-50%)
- **연간 약 1,000시간 절감** = 정규직 0.5명 분량
- 절감된 시간을 **분석·개선·후임 양성·OEM 대응**으로 재배치

## 2. 정량 효과 (KSF 기반)

| 지표 | 현재 (검증완료) | 목표 (도입 12개월 후) | 사업적 의미 |
|---|---|---|---|
| **KSF-1 납기 준수율** | 93% | **≥ 99%** | OEM 페널티/긴급출하 비용 ↓, 신뢰도 ↑ |
| **KSF-2 다이/노즐+금형 변경** | 일 5~10회 (월 ≈ 165회) | **-30%** (월 ≈ 115회) | 라인 비가동 시간 월 55~110시간 → 월 38~77시간 |
| **KSF-3 변동 영향 파악 시간** | 4시간 | **≤ 5분 (-98%)** | 즉답·즉응 가능, OEM·이사회 의사결정 속도 ↑ |
| **KSF-4 스케줄링 작업시간** | 주 4시간 (정기) + 변동 대응 주 20시간 | **-50%** | 연간 ≈ 1,200시간 → 600시간 |
| **KSF-5 데이터 일원화** | 0% (엑셀 3종 분산) | **100%** (단일 DB) | 인수인계·신뢰성 ↑ |
| **KSF-6 시스템 채택률** | - | **≥ 90%** (3개월 후) | UX·자동+수동 보정 철학으로 보장 |

> **단가 검증 보류** (이사님 결정): 시간당 라인 가동비·인건비·OEM 페널티 단가는 차후 보강. 현 시점에서도 **시간 절감만으로 정규직 0.5명 분량 가치 확보 = 충분한 도입 정당성**.

---

## 3. 정성 효과

- **OEM 신뢰도 강화** — 납기율 99% + 변동 영향 즉답 → 추가 수주 기반
- **베테랑 리스크 해소** — 휴가·이직·인사이동 시 운영 차질 해소
- **데이터 기반 경영** — 6개 KSF 실시간 모니터링으로 의사결정 정확도 ↑
- **현장 만족도 ↑** — 야근 -50%, "수동 조정 권한 보장"으로 베테랑 자율성 유지
- **인수인계·교육 단축** — 제약변수 명문화로 신입 양성 부담 ↓

## 4. 전략 효과 (확장성)

```
[Phase 0] 실리콘 47품번 (1차 도입) ─── 검증 ──→
[Phase 1] EPDM·NBR 등 타 재료군 확대 ─────→
[Phase 2] 타 공장·해외 법인 확대 ──────────→
[Phase 3] (옵션) SaaS化 — 동종 업계 판매
```

- 처음부터 **재료 구분 필드 + Cloud-Ready 설계 (12-Factor)**로 확장성 확보
- D8 사내망 정책 변경 시 **3~6개월에 클라우드 이전 가능** (이전 비용 90% 절감)
- 미래 클라우드 → SaaS 사업 옵션 유지

## 5. 비용 vs 효과 (ROI 1차안)

### 투자 (Phase C 후 견적 확정)
- **개발**: 외주 또는 사내 인력 채용 (TBD — Phase C 종료 시점에 견적)
- **인프라**: 사내 서버 1대 (CPU 8c / RAM 32GB / SSD 500GB)
- **운영비**: 유지보수 (월 TBD)
- **기간**: 기획 6~8주 + 개발 6~9개월

### 효과 (정량)
- **시간 절감**: 연간 ≈ **1,000시간** (정규직 0.5명 분량)
- **공정 손실 감소**: 다이/노즐+금형 변경 -30% × 라인 비가동 시간
- **납기 페널티 감소**: 사고율 7% → 1% (-86%)
- **추가 수주 가능성**: OEM 신뢰도 강화 효과 (정성)

### 회수 기간 목표
**18개월 이내** (단가 검증 후 정밀 산출)
