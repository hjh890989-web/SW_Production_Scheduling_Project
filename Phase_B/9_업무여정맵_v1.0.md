| 월 10:00~11:00 | **본 시스템 통합 입력 화면**에 한 번 입력 (엑셀 업로드 또는 직접 폼) | 본 시스템 | 😊 | **통합 입력 1회로 끝** (R-7 확장 검토) |
| 월 11:00 | 시스템 자동 검증 (품번 마스터 매칭, 이상치 알림) | 본 시스템 | 😊 | 양식 불일치 실수 ↓ |
| 월 11:00 | 자동으로 생산관리·현장에 알림 발송 | 본 시스템 | 😊 | 메일·카톡·전화 X |
| **화~목** | OEM 변동 발생 → 시스템에 즉시 입력 | 본 시스템 | 😊 | 사내 반영 즉시 (R-7) |
| 화~목 | 시스템이 변동 영향을 자동 분석 → 본인은 결과만 확인 | 본 시스템 | 😊 | 사내 반영 여부 자동 확인 |
| 금 17:00 | 주간 마감, audit 로그로 본인 입력 이력 자동 정리 | 본 시스템 | 😊 | **책임 명확** |
| **변동 잦은 주** | 시스템이 자동 처리 → 야근 ↓ | - | 😊 | 야근 ↓ |

### 핵심 변화
- **수주 입력 1회로 끝** — 본 시스템 통합 GUI에 한 번 입력하면 자동 분배
- **본인 책임 추적 가능** — 모든 입력에 audit 로그
- **외부 채널 다양성은 그대로** — 그러나 사내 통합 시점은 1회

→ 이 페르소나의 큰 깨달음: **R-7을 "변동 입력"에서 "수주 + 변동 통합 입력"으로 확장 필요** (Phase C PRD 정식 반영)

## 부록 A. 종합 통찰 — 5개 여정맵에서 도출된 시스템 설계 함의

### A.1 공통 패턴 — 모든 페르소나에서 반복되는 As-Is 통증

| 통증 | 빈도 | 시스템 해결책 |
|---|---|---|
| **"여러 채널·여러 곳에서 정보 수신"** | 5명 모두 | 통합 입력·통합 대시보드 |
| **"머리로 계산·판단해야 함"** | 김민수·박철수·이영호 | 자동 초안 + 수동 보정 (D10) |
| **"누가 언제 무엇을 했는지 추적 곤란"** | 5명 모두 | Audit 로그 (R-13) |
| **"인수인계·휴가 시 차질"** | 박철수·김민수 | 시스템 명문화 + 권한 위임 |
| **"변동 → 재작업 → 야근"** | 김민수·정수진 | 자동 영향 시뮬 (R-8) |

### A.2 페르소나별 채택 결정 요인 (Make or Break)

| 페르소나 | Make (채택 강화) | Break (채택 실패) |
|---|---|---|
| 김민수 | 변동 영향 5분 내 확인 | 자동 결과만 강제 |
| **박철수 ⭐** | **수동 보정 권한 + 큰 글씨 UI** | **자동 강제 + 복잡한 화면** |
| 이영호 | E그룹 묶음 시각화·본인 KPI | 부하 분산 결과 불투명 |
| 정수진 | 통합 입력 1회 | 양식별 입력 강제 |
| 경영진 | 모바일 KSF 한 화면 | 대시보드 부재 |

### A.3 As-Is → To-Be의 시간 효과 (정량)

| 페르소나 | As-Is 시간 | To-Be 시간 | 절감 |
|---|---|---|---|
| 김민수 | 주 24시간 (변동+정기) | 주 12시간 | **-12시간/주** |
| 박철수 | 머리 계산·일지 1.5시간/일 | 0.5시간/일 | **-1시간/일** |
| 이영호 | 다이 변경 결정 0.5시간/일 + 일지 | 0.2시간/일 + 자동 | **-0.4시간/일** |
| 정수진 | 통합 4시간/주 + 변동 야근 | 1.5시간/주 | **-2.5시간/주** |
| 경영진 | 분기 보고 며칠 | 30분 | 시간 ↓ + 의사결정 정확도 ↑ |

→ **연간 환산 약 1,000시간 이상 절감 추정** (사내 인건비 단가 검증 시 ₩환산 가능)
