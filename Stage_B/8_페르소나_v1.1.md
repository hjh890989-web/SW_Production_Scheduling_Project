## 페르소나 1 — 생산관리 담당자 **김민수 과장**

### 프로필
- **나이·연차**: 38세 / 12년차
- **소속**: 생산관리팀
- **학력·배경**: 산업공학 학사. 고무·자동차부품 도메인 경험 풍부
- **디지털 친숙도**: ★★★★☆ (엑셀 고수, ERP 사용 능숙, 신기술 학습 의지 있음)

### 핵심 직무
- 매주 목요일 영업팀에서 받은 주간 계획을 바탕으로 **성형·압출 일정 수기 작성**
- 매일 변동(수량/일자/추가/취소) 대응 — **주 평균 5회**
- 현장 반장과 일일 협의 (조회·통화)
- MES 작업실적과 계획 대조 (수기)

### 시스템 사용 패턴
- **사용 빈도**: 매일 평균 4시간 이상
- **주 사용 화면**: 통합 대시보드, 성형 간트, 압출 간트, 변동 입력
- **디바이스**: 데스크탑 (주 8시간), 태블릿 (현장 이동 시)

### 주요 니즈 (시스템에 바라는 것)
1. **수주 변동 시 5분 안에 영향 파악** (현재 4시간 소요)
2. 자동 백워드 스케줄링으로 D-2/D-1 룰 자동 보장
3. 한 화면에서 수주 → 압출 → 성형 → 실적 전체 추적
4. 주간 계획 작성 시간을 절반으로 (현재 주 4시간)
5. **수동 보정 자유도 보장** (시스템이 자동 결정만 하지 않기)

### 페인포인트 (현재 겪는 통증)
- 🔴 **베테랑 1인 의존 — 휴가 시 후임이 즉시 대체 불가**
- 🔴 **변동 발생 시 수기 재계산** → 야근·주말 출근 잦음
- 🔴 **생산 자원 문제 발생 시 대응에 많은 시간 소요** — 설비 고장, 자재 부족, 인원 부족(연차 등) → 매번 전체 일정 재구성 (v1.1 추가)
- 🟡 영업·현장 사이에서 끊임없는 전화·메일 중계
- 🟡 진행 중인 압출/성형 건이 변동 영향받는지 매번 일일이 확인
- 🟡 OEM 페널티 발생 시 책임 추적 어려움 (이력 부재)

### 도입 후 가장 큰 변화
- 변동 영향 자동 시뮬레이션 → **즉답 가능**
- 야근 감소 → **삶의 질 개선**
- 자신의 노하우(제약변수)가 시스템에 흡수되어 후임 양성 가능
- **자원 이상(설비/자재/인원) 발생 시 영향받는 건을 시스템이 자동 식별** → 재계획 시간 단축 (v1.1 추가)

### 이 페르소나의 JTBD (Top 3)
1. **주간 회의에서 "수주 X 변경 시 영향"을 즉답하기 위해, 변동 입력 즉시 영향을 5분 안에 시각화하고 싶다**
2. **D-2/D-1 납기 룰을 위반하지 않기 위해, 시스템이 자동으로 백워드 스케줄을 생성하되 내가 최종 수동 조정하고 싶다**
3. **휴가·인수인계 시 후임이 당황하지 않도록, 모든 제약변수와 변경 이력이 시스템에 명문화되어 있기를 원한다**

## 페르소나 2 — 현장관리자(성형) **박철수 반장**

### 프로필
- **나이·연차**: 49세 / 25년차
- **소속**: 성형(가류) 공정 현장
- **학력·배경**: 공업고졸. 가류·금형 베테랑. 도메인 지식 최고 수준
- **디지털 친숙도**: ★★☆☆☆ (스마트폰·카카오톡 능숙, 엑셀은 단순 조회만, 신시스템 거부감 있음)

### 핵심 직무
- 가류기 4대(저압) + 1대(IC) 일일 가동 책임
- 슬롯 배치·앵글 셋팅·금형 교체 결정
- 교대 인수인계 (주야 2교대)
- 작업 실적 일지 작성 (수기 → MES 입력은 지원직이 함)

### 시스템 사용 패턴
- **사용 빈도**: 매일 짧게 (총 30분~1시간)
- **주 사용 화면**: 본인 가류기 스케줄 조회, 실적 입력
- **디바이스**: 현장 태블릿 (주 사용), 데스크탑 (가끔)

### 주요 니즈
1. **단순한 화면** — 복잡한 메뉴·팝업 X, 큰 글씨·버튼
2. 본인 공정 일정만 명확히 (다른 정보로 어수선하지 않게)
3. 작업지시서 종이 인쇄 가능
4. 실적 입력 1탭으로 끝나기

### 페인포인트
- 🔴 **새 시스템 = 거부감** (수기 일지가 익숙)
- 🔴 **슬롯 배치·앵글 셋팅·금형 교체 결정 = 본인 25년 경험에 의존 → 타인에게 위임 불가** (v1.1 추가)
- 🔴 **앵글 셋팅 시 위치 제약조건이 많아 "한 번에" 계산 불가** — 여러 시도·검토를 거쳐야 가능 (v1.1 추가)
- 🔴 작은 글씨·복잡한 화면이면 사용 안 할 가능성
- 🟡 생산관리 담당자와 매번 전화로 일정 변경 통보받음
- 🟡 베테랑 본인의 노하우가 시스템에 어떻게 흡수될지 불안

### 도입 후 가장 큰 변화
- 일정이 명확해져 전화·문의 감소
- 인수인계 시 시스템이 자동 정리해주므로 부담 감소
- 단, **시스템이 본인 판단을 무시하면 도입 실패** → 수동 조정 권한 필수

### 이 페르소나의 JTBD (Top 3)
1. **새벽 교대 직후 오늘 무엇을 만들지 빠르게 알기 위해, 태블릿 한 화면으로 본인 가류기의 일정을 보고 싶다**
2. **자동 스케줄이 현장 직관과 어긋날 때, 시스템이 강제하지 않고 내 수동 보정을 받아주기를 원한다**
3. **회사가 내 25년 노하우를 인정해주기 위해, 마스터 데이터(슬롯 위치 가능 여부, 앵글 보유수 등)에 내 의견이 반영되기를 원한다**

### ⚠️ 채택 리스크 — 본 페르소나의 거부 = 도입 실패
- Phase B-3 인터뷰 1일을 통해 페인포인트·요구사항 직접 청취 필수
- UI 단순화·큰 글씨·자동+수동 철학 엄수가 채택률을 좌우

- 주야 **2교대** (각 교대는 전반/후반 근무로 분할) 인수인계

2. E그룹·헤드핀 묶음을 시각적으로 확인
3. 신규/포드 부하 분산 결과를 명확히
4. 변경 시 "왜 이 일정이 나왔는지" 근거 표시 (블랙박스 X)

- 🔴 다이/노즐 변경 시 폐기량·워밍업 시간 손실이 누적되나 **수치화 안 됨**
- 🟡 E그룹 묶음 최적화는 시간 부족으로 포기됨 (사람이 매번 풀기 어려움)
- 🟡 관체 공급 지연 시 성형 측 압박

### 도입 후 가장 큰 변화
- 다이/노즐 변경 횟수가 KPI로 측정됨 → 본인 노력 가시화
- E그룹 자동 묶음으로 셋업 손실 ↓
- 신규/포드 부하 균형이 자동 계산

### 이 페르소나의 JTBD (Top 3)
1. **다이/노즐 변경 횟수를 줄이기 위해, 시스템이 같은 E그룹·헤드핀의 품번들을 한 근무시간에 묶어 배치해주기를 원한다**
2. **납기 위반을 피하면서도 셋업을 최소화하기 위해, 자동 일정 + 내 수동 미세조정이 모두 가능하기를 원한다**
3. **신규/포드 가동률을 균형 있게 유지하기 위해, 시스템이 부하 분산을 자동 계산하되 결과를 시각적으로 보여주기를 원한다**

- **디지털 친숙도**: ★★★★☆ (엑셀 능숙, 영림원 ERP 사용)

- 변동 발생 시 생산관리팀에 1차 통보 (메일·메신저·전화)

### 시스템 사용 패턴
- **사용 빈도**: 주 단위 (수주 발생 주기에 따라 1~3회/주)
- **주 사용 화면**: 수주 업로드, 변동 입력, 통합 대시보드 (수주만 조회)
- **디바이스**: 데스크탑

### 주요 니즈
1. **3종 엑셀을 통일된 양식으로 입력** 또는 기존 양식 그대로 업로드 가능
2. 변동 발생 즉시 시스템에 입력 → 생산관리팀에 자동 통지
3. 월예상↔주간확정 차이 자동 분석 (영업 측 forecast 정확도 측정용)
4. 본인 입력 이력 추적 가능

### 페인포인트
- 🔴 **수주 정보 최초 접수 채널이 다양함** — 엑셀파일·메일·전화·카카오톡 등 → **최초 통합 자체에 시간 소요**, 이후 사내 양식으로 정리·전달까지 다단계 작업 (v1.1 추가)
- 🔴 같은 수주 정보를 3종 엑셀에 다르게 입력하다가 실수 발생
- 🔴 변동 통보 후 생산팀 측 반영 여부를 본인이 다시 확인해야 함 (메일·전화 추적)
- 🟡 OEM 측에서 변경 잦으면 본인이 야근

### 도입 후 가장 큰 변화
- 수주 입력 1회로 끝 (3종 양식의 자동 매핑)
- 변동 통보 → 시스템 자동 반영 → 생산팀 즉시 인지
- 본인 책임 범위 명확 (audit 로그)

### 이 페르소나의 JTBD (Top 2)
1. **OEM 발주를 정확하게 사내에 전달하기 위해, 3종 엑셀을 한 번 업로드하면 시스템이 자동으로 통합·매핑해주기를 원한다**
2. **변동 발생 시 책임 소재를 명확히 하기 위해, 내가 입력한 변동이 시스템에 기록되고 생산팀에 즉시 알림이 가기를 원한다**

- **주 사용 화면**: KPI 대시보드 (P2 단계 산출), 변경 이력 요약
- **디바이스**: 데스크탑 (사무실), 모바일 (이동 중·재택)

### 주요 니즈
1. **6개 KSF의 실시간 추이** (납기율·전환손실·변동대응시간 등)
2. 이상치(납기 위반 등) 즉시 알림
3. 미래 확장(EPDM·다른 공장·클라우드)에 본 시스템이 어떻게 대응할지 가시화
4. 외주·인력 비용 대비 ROI 추적

### 페인포인트
- 🔴 의사결정에 필요한 데이터가 흩어져 있어 즉답 불가
- 🔴 OEM 측 클레임 발생 시 사내 책임 소재 추적 어려움
- 🟡 베테랑 의존 리스크가 시스템화되지 않은 상태

### 도입 후 가장 큰 변화
- 데이터 기반 의사결정 가능
- OEM 신뢰도 강화 → 추가 수주 기반
- 미래 확장 옵션 확보 (Cloud-Ready)

### 이 페르소나의 JTBD (Top 2)

2. **본 시스템 도입의 ROI를 입증하기 위해, 도입 전후 KSF 변화 추이가 자동 비교되기를 원한다**

- **박철수**: "내 25년 노하우를 무시하지 마라" (수동 조정 권한)
- **이영호**: "다이/노즐 변경 횟수가 KPI로 측정되어야 한다"
- **정수진**: "수주 입력 1회로 끝, 변동도 시스템에 한 번만"
- **경영진**: "ROI와 6개 KSF가 한 화면에 나와야 한다"

### UX 설계 원칙 (페르소나에서 도출)
1. **베테랑 반장 페르소나(2·3) 친화 UI** — 큰 글씨·단순 메뉴·명확한 색상 코딩 (품번/E그룹)
2. **자동 + 수동 보정 철학** (D10) 모든 화면에 적용

4. **데스크탑 + 태블릿 반응형** — 현장 태블릿 최적화
