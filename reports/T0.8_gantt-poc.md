## 3. 결정 — frappe-gantt 채택

**채택 사유**:
1. **MIT 라이선스 → D8 정책 안전, 비용 0원**
2. **번들 가벼움 (30KB)** — 사내 1Gbps LAN에서도 초기 로딩 빠름
3. **vanilla JS + SVG** — 박철수 반장 친화 UX 커스터마이징 자유도 최대
4. **47품번 규모에 충분** — 가상 스크롤 미지원이 문제 안 됨
5. **벤더 락인 없음** — 향후 EPDM/NBR 확장 시 자체 fork 가능

**한계 및 대응**:
- 의존성 라인 미지원 → P2(Sprint 12)에서 SVG `<path>` 직접 그려 구현
- TypeScript 타입은 `@types/frappe-gantt` 커뮤니티 패키지 또는 자체 d.ts 작성
- React 통합: 얇은 wrapper 컴포넌트 `<GanttChart>` 자체 작성 (~30 라인)

**대안 폴백**:
- 만약 T5.6 PoC에서 frappe-gantt 한계 발견 시 → DHTMLX Gantt GPLv2 검토 (D8 호환)
- Bryntum은 라이선스 서버 호출 검증되지 않으면 제외
