## 🧪 Acceptance Criteria
### AC T0.4-1 (정상)
- **Given**: schema.prisma 작성 완료
- **When**: `npx prisma migrate dev`
- **Then**: SQLite DB 생성, 12개 테이블 + index 생성, 마이그레이션 파일 기록

### AC T0.4-2 (정상)
- **Given**: Prisma Client 생성됨
- **When**: 코드에서 `import { prisma } from '@/lib/db'`
- **Then**: 타입 안전한 모든 모델 접근 가능 (자동 완성)

### 🔥 AC T0.4-F1 (실패 — 스키마 검증)
- **Given**: schema.prisma에 잘못된 관계 정의
- **When**: `prisma validate`
- **Then**: 명확한 에러 위치 + 수정 가이드

## ⚙️ Constraints
- **개발 DB**: SQLite, 운영은 PostgreSQL (URL만 변경)
- **Json 타입**: SQLite 호환 위해 String으로 저장 (PostgreSQL 이전 시 강화)
- **Audit 5년**: AuditLog 테이블 인덱스 (`createdAt`, `userId`, `targetTable`)
