## 🧪 Acceptance Criteria
### AC T0.1-1 (정상)
- **Given**: 프로젝트 루트 (기존 Stage_*, .claude/, .agents/ 등 보존)
- **When**: `npx create-next-app@latest . ...` 실행 + 의존성 설치
- **Then**: `npm run dev` 정상 동작, `http://localhost:3000` 접근 시 기본 페이지 표시 (응답 ≤ 3초). 기존 문서 폴더는 영향 없음

### AC T0.1-2 (정상)
- **Given**: 프로젝트 생성 완료
- **When**: `npm run build && npm run lint`
- **Then**: 빌드·린트 모두 통과 (오류 0)

### 🔥 AC T0.1-F1 (실패 — Node 버전 불일치)
- **Given**: Node 버전 < 20 LTS
- **When**: `create-next-app` 실행
- **Then**: 명확한 에러 메시지 + `.nvmrc` 파일에 "20" 기록 권고
