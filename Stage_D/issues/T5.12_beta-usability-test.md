## ✅ Task Breakdown

### 사전 준비 (1h)
- [ ] 박철수 반장(성형), 이영호 반장(압출) 일정 1일 확보 (사내 협조 요청)
- [ ] 프로토타입 환경 준비: T5.4(W-4 Grid) + T5.6(드래그) 최소 동작 버전
- [ ] 가짜 데이터 시드: 실리콘 47품번 중 10품번, 5일치 스케줄

### 테스트 진행 (4h) — 사내 회의실 또는 현장 PC
- [ ] 박철수 반장 세션 (90분)
  - [ ] 시나리오 5건 hands-on (반장이 직접 드래그)
  - [ ] 각 시나리오 종료 후 만족도 1~5 점수
  - [ ] 자유 발화 녹취(동의 시) 또는 메모
- [ ] 이영호 반장 세션 (90분, 동일 구성, 압출 시나리오로 일부 변형)
- [ ] 종합 디브리핑 (60분) — 두 반장 합석, 핵심 이슈 토론

### 결과 분석 및 반영 (3h)
- [ ] 만족도 점수 집계 (5점 만점, 4점 이상이 KSF-6 ≥90% 채택 가설 지지)
- [ ] 핵심 발견 3~5건 정리 (지킬·고칠·버릴 분류)
- [ ] 시뮬레이션 인터뷰(Stage_B/15) 가설과 일치·불일치 항목 표시

## 🧪 Acceptance Criteria

### AC T5.12-1 (정상)

- **Given**: 핵심 발견 정리
- **When**: T5.6 issue 파일 DoD를 갱신
- **Then**: "T5.12 사용성 테스트 결과 반영" 항목이 ✅로 표시 가능

- **Then**: **즉시 Sprint 5 진행 중단** + 재설계 ADR(D-23) 발의 + PM/이해관계자 회의 소집

- **Then**: PM에게 에스컬레이션 + 화상 30분 단축 버전(J-MR-2 시나리오 2건만)으로 대체 진행
