## 🧪 Acceptance Criteria

### AC T0.8-1 (정상)
- **Given**: 후보 3종 이상 비교 완료
- **When**: 평가 매트릭스 작성
- **Then**: 1개 선정 + 결정 근거 문서(라이선스·기능·성능·UX 4개 영역) 작성

### AC T0.8-2 (정상)
- **Given**: 선정 완료
- **When**: `npm install <선정 라이브러리>` 실행
- **Then**: 빌드 통과 + 최소 PoC 데모 페이지 동작

### 🔥 AC T0.8-F1 (실패 — 유료 라이선스 사내 정책 위반)
- **Given**: Bryntum / DHTMLX 등 유료 라이선스가 사내 IT 정책 거부
- **When**: 결정 시점
- **Then**: 무료 대안(frappe-gantt 또는 custom react-big-calendar)으로 자동 fallback + 결정 문서에 사유 명시

### 🔥 AC T0.8-F2 (실패 — 드래그 응답 ≤500ms 미달)
- **Given**: PoC 결과 드래그 응답이 500ms 초과
- **When**: 측정 완료
- **Then**: 해당 후보 탈락 + 다음 후보 PoC 진행 + 모두 미달 시 custom 구현 옵션을 Sprint 5 진입 전 의사결정
