## 🧪 Acceptance Criteria

### AC T5.1-1 (정상)
- **Given**: T0.8에서 결정된 라이브러리
- **When**: `npm install` + `npm run build`
- **Then**: 빌드 통과 + 메인 번들 사이즈 영향 ≤200KB

### AC T5.1-2 (정상)
- **Given**: 도메인 데이터 어댑터 구현 완료
- **When**: 더미 데이터 7일 × 5 가류기 × 14 슬롯 입력
- **Then**: 그리드가 정상 렌더링 + 색상 코딩 표시 + 키보드 Tab 이동 가능

### 🔥 AC T5.1-F1 (실패 — T0.8 결정이 변경되어야 하는 상황)
- **Given**: 통합 중 PoC에서 발견되지 않은 치명적 문제 (예: SSR 호환 불가, 라이선스 정책 변경)
- **When**: 통합 시도
- **Then**: 즉시 멈춤 + ADR D-23 보강 발의 + T0.8 재진입 결정 (PM 합의 후)

## ⚙️ Constraints
- **사내망 호환**: CDN 의존 X, 모든 자산은 npm 패키지로 번들
- **번들 영향**: 메인 번들 증가 ≤200KB
- **SSR/CSR**: Server Component에서는 메타데이터만, 인터랙티브 영역은 `'use client'` 명시
