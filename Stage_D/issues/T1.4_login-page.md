## 🧪 Acceptance Criteria
### AC T1.4-1 (정상)
- **Given**: 등록된 사용자
- **When**: ID/PW 입력 + 로그인
- **Then**: 대시보드(`/`) redirect, 응답 ≤ 1초

### AC T1.4-2 (정상 — Zod 검증)
- **Given**: 빈 ID 또는 짧은 PW
- **When**: 제출
- **Then**: 인라인 빨간 에러, 제출 차단

### 🔥 AC T1.4-F1 (실패 — 5회 잠금)
- **Given**: 4회 실패 후 5번째 시도
- **When**: 잘못된 PW 입력
- **Then**: "5분 동안 잠겼습니다" 메시지 + 입력 비활성화, lock_until DB 기록

## ⚙️ Constraints
- **글씨**: ≥ 16px (베테랑 친화)
- **버튼**: ≥ 44×44px
- **제출 응답**: ≤ 1000ms
